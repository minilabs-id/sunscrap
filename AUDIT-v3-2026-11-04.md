## 1. TEMUAN TERBESAR (baru, terukur): mesin intel kolaps pada data farm skala penuh

Diukur langsung di DB `:memory:` (akun TikTok, 10 post/akun, bio seragam — kasus farm nyata):

| Jumlah akun | Waktu `snapshotFromRows` |
|---|---|
| 300 | 0,48 dtk |
| 600 | 2,5 dtk |
| 900 | 23 dtk |
| **1.500** | **65–82 dtk** (`getAccountIntel` limit 50 / `getAccountDetail`) |
| 1.500, query per keystroke (`q="farm_07"`) | 74 dtk |

**Penyebab struktural:** satu token bio dipakai semua akun → `_pairOff` membentuk semua pasangan (C(1500,2) ≈ **1,1 juta edge**, tiap edge = object + `Map` + `Set`), `peer_reasons` ≈ 2,2 juta entri, lalu `analyseAccount` mem-join 1.499 nama per akun × 1.500 akun. Kompleksitas efektif **super-kuadratik** + ratusan MB alokasi. Dipanggil **per tab Akun dibuka, per refresh dashboard, per keystroke** di kotak cari.

**Konsekuensi:** semakin persis data yang dicari alat ini (akun ternak masal), semakin mustahil alat ini selesai → **false negative** (tidak ada yang terdeteksi; UI beku) + **false positive** (seluruh cluster dipaksa menjadi satu grup "ternak").

**Wajib (bukan nice-to-have):**
1. **Fan-out cutoff:** token/hotline dipakai >50 akun (atau >5% korpus) = `common_token` — dicatat, **tidak** dijadikan bukti pasangan; cluster strong butuh ≥2 sinyal independen atau 1 strong + ≥1 lain.
2. **Materialisasi `intel_snapshot`** + TTL/invalidasi generasi — jauh lebih murah daripada komputasi penuh per request; `getAccountIntel`/`getAccountDetail` jadi O(halaman).
3. Kohort-baseline (flag hanya bila < persentil-10 atau < 0.5× median kohort audit), dedup `post_ref` sebelum burst, dan **satu** titik `FLAGGED_SCORE` (hapus opsi `curiga` yang tumpang tindih).

## 4. Model ancaman & failure modes (baru, STRIDE-lite)

**Spoofing / phishing** — Tab Browser memuat URL arbitrer di partisi sesi login (`persist:sunscraping`); `will-navigate` meloloskan **semua** `file://` (dokumen lokal mewarisi preload dengan `clearAll`/`deleteAudit`); `will-attach-webview` hanya memaksa `nodeIntegration:false` + `contextIsolation:true` + hapus preload — **tidak memaksa `sandbox:true`** pada guest. → allowlist IG/TikTok + `sandbox:true` guest + `will-navigate` hanya `renderer/index.html`.

**Tampering** — backup tidak pernah diverifikasi (tanpa `integrity_check`); DB plaintext (bio = PII) tanpa checksum; WAL/SHM bisa disalin setengah jalan (sudah ditangani fix backup atomik ✅).

**Repudiation** — **tidak ada audit log aksi** (siapa menghapus audit mana, kapan backup dibuat) — fatal untuk "alat bukti". Tambahkan log file rotasi (`userData/logs/`, maks 5×2 MB) tanpa PII; sertakan `taskId`, `runId`, `durationMs`, `errorCode`.

**Information disclosure** — bio HP/email plaintext; backup `.db` tidak terenkripsi; error IPC bisa membocorkan path absolut; sesi IG tertinggal di disk setelah uninstall (tombol hapus ada, tetapi tidak otomatis/diberitahu).

**Denial of service** — self-DoS import sudah dicap ✅; sisa: `loadURL` hang **selamanya** (P0 §10); intel O(n²) (§1); `VACUUM INTO` butuh ±2× ukuran DB **tanpa cek ruang disk** (gagal → tetap aman berkat temp+rename, tetapi pengguna tidak tahu penyebabnya).

**Elevation** — preload bridge luas (delete/clear-all) tanpa rem tambahan (mitigasi: CSP ketat ✅); `style-src 'unsafe-inline'` bisa dibuang dengan memindahkan inline style ke kelas.

**Failure modes operasional**

| Kejadian | Perilaku sekarang | Seharusnya |
|---|---|---|
| Markup IG/TikTok berubah | PARTIAL/FAILED massal tanpa alert | metrik kesehatan per platform + alert di Proses |
| Koneksi putus tengah navigasi | **hang permanen** | timeout `loadURL` → destroy → FAILED/TRANSIENT |
| Sesi expired | AUTH → backoff, tetap ditembak 3× lalu berhenti ✅, **tanpa banner "Login diperlukan"** | banner + tombol Login langsung |
| DB korup | tidak ada `integrity_check` / restore-test | cek + uji restore bulanan |
| Disk penuh | backup gagal (error ditampilkan, backup lama aman ✅) | pra-cek ruang ≥ 2× ukuran DB |
| Crash tengah klaim | reclaim 5 mnt ✅ | tetap |
| `SA_USER_DATA` salah | dua DB paralel diam-diam | log path DB di boot (sudah) + peringatan env |
