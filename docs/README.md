- **Bahasa**: Indonesia (kode & komentar), istilah teknis Inggris bila baku.
- **Referensi `file:baris`** mengacu ke commit saat dokumen ditulis; verifikasi ulang bila banyak berubah.
- **Audit bersifat historis.** Temuan yang sudah diperbaiki tetap dicatat di `AUDIT-HISTORY.md` agar keputusan lama tidak diulang tanpa konteks.
- Dokumen di folder ini adalah **satu-satunya sumber dokumentasi**; arsip audit lama sudah dikonsolidasikan ke sini dan dihapus dari root.
